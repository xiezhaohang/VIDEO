# 口播驱动商品剪辑规则

> 来源：充电宝口播驱动 V1 / V2 人工对比审片。只记录已经通过实际成片验证的规律。

## 1. 主原则

口播驱动剪辑的核心不是“每句话找一个画面”，而是：

`表达意图 → 视觉对象 → 动作/结果峰值 → 人眼可读时间 → 下一语义段`

画面负责证明口播，不是简单陪跑。

## 2. 先拆表达意图，不按句号机械切

每段口播至少输出：

- `spoken_text`
- `intent`
- `selling_point`
- `required_visual`
- `proof_required`
- `ideal_visual_peak`

切镜依据优先级：

1. 语义变化点
2. 动作变化点
3. 口播重音点
4. 句法停顿

句号不能直接等同于剪切点。

## 3. 口播—画面覆盖矩阵

每个语义段必须标记：

- `exact_match`
- `partial_match`
- `no_match`
- `proxy_visual_allowed`
- `proof_missing`

规则：

- exact_match：可以承担功能证明
- partial_match：只能辅助表达，不能冒充完整 Proof
- no_match：禁止用“差不多”的镜头制造不存在的事实

V2 验证：TSA、墙插、促销无直接素材时，诚实使用中性 B-roll 比伪造证明更自然。

## 4. A-roll 与 B-roll 分工

### A-roll

承担：

- 功能动作
- 功能结果
- 核心卖点
- 关键 Proof

必须语义强对应，并满足动作闭环。

### B-roll

承担：

- 痛点
- 便携
- 旅行便利
- 产品氛围
- 过渡
- 结构补充

B-roll 不要求逐词同步，但必须服务当前表达。

## 5. 重音同步：同步动作峰值，不是只同步镜头开始

真正重要的是让视觉峰值落在口播关键词附近。

例如：

- `charges your phone` → Charging 状态出现
- `watch` → 手表充电绿灯出现
- `magnetic / snap` → 实际接触/吸附瞬间

规则：

- 允许画面相对声音提前或延后约 0.2–0.8 秒
- 目标是“语义峰值对齐”，不是“每个单词换一镜”

V2 验证：磁吸接触落在 `snap` 附近，广告感显著强于 V1。

## 6. Proof 对词准确后，仍必须给足可读时间

对词更准不等于更好。

V2 手表段验证：

- 绿灯落点更准
- 但绿灯完整可读时间只有约 0.30 秒
- 真人观感弱于 V1 约 1 秒的稳定停留

因此：

> `sync_accuracy` 不能覆盖 `human_readability`。

核心 Proof 必须同时满足：

- 峰值靠近关键词
- 结果明确出现
- 结果有足够稳定可读时间

## 7. 禁止“逐词打卡式剪辑”

V2 后半段验证：

- 为不同短语频繁拆分近似产品特写
- 13.20–16.40 秒出现同源素材重叠与接口动作重复
- 造成明显机械感

规则：

- 不要因为口播出现新名词就强制换镜
- 同一连续 B-roll 如果能自然覆盖完整语义段，优先保持连续运动
- 相似角度/相似动作不得为“对词”重复使用

## 8. 后半段缺素材时，连续自然优先于频繁代理

当 TSA、墙插、旅行、促销等缺直接素材时：

- 少量中性 B-roll 可接受
- 频繁切近似产品特写会放大“素材不足感”
- 与其逐词找代理，不如保留一段连续、动作自然的产品展示

V1 在 TSA/酒店前半段的连续性优于 V2。

## 9. 功能序列需要呼吸，不要变成“功能清单”

手机 → 手表 → 耳机如果连续快速出现，虽然语义正确，也可能产生 checklist 感。

建议：

- 核心 Proof 之间保留微小呼吸
- 状态重置要明确
- 功能段不能只追求对词速度

## 10. CTA 前必须制造层次升级

V1 的：

`多设备总结 → 单产品 hero`

比 V2 的：

`手持产品 → 手持产品 hero`

收束更强。

规则：

- hero shot 前一镜应尽量在信息、景别或构图上形成反差
- CTA 前不要连续使用两个近似手持产品镜头
- 结尾需要“升级感”，不是又一段同类展示

## 11. 下一版融合规则

经 V1/V2 审片，最佳方向不是二选一，而是融合：

- 前半：采用 V2 的表达意图与重音同步逻辑
- 手表：恢复 V1 的 Proof 可读时间
- 磁吸：保留 V2 的结构预读 + snap 峰值
- 后半：恢复 V1 的连续运动，避免接口重复
- 多设备段：保留 V2 在 `charging all your devices` 的匹配
- CTA：恢复 V1 的 `多设备总结 → hero` 层次

## 12. 人工审片必须同时评估三件事

1. `semantic_match`：画面是否说对了
2. `proof_readability`：结果是否看得清
3. `editorial_flow`：整条是否自然、像广告

任何一项高，不能掩盖另外两项低。
