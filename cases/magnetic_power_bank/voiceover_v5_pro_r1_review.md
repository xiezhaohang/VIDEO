# Voiceover V5-Pro-R1 人工/复核审片记录

## 结论

`voiceover_cut_v5_pro_r1.mp4` 相对 V5-Pro 为真实提升，并达到当前素材条件下纯剪辑阶段的合理上限。无必修问题，不建议为了继续而再剪一版。

## 关键验证

### 1. Hook 动作语义修复

00:00–03:50 使用 `DJI_20260801170103_0106_D.MP4` 00:00–03:50。

产品始终留在画面，正面 → 背面磁吸区域 → 手指演示，动作语义为正向展示。

V5-Pro 中 `0109 03.700–07.200` 的向右甩出动作及约 1.75 秒 dead tail 已消除。

新增通用判断：

- `action_sentiment_to_target_product = positive | neutral | negative | ambiguous`
- Hook / 产品揭示阶段只允许 positive 或明确 neutral。
- negative / ambiguous 的甩开、推远、离场、丢弃类动作必须淘汰，即使它与口播重音对齐。

### 2. readability_tail 与 dead_tail 必须区分

V5-Pro 暴露：动作结束后长时间停住，只为了等待口播，会形成 dead tail。

V5-Pro-R1 验证：前 3 秒持续存在手指/持握变化和产品信息增量，不构成明显停顿。

规则：

- `readability_tail`：为看清结果服务，可保留。
- `dead_tail`：动作结束后无新信息，仅等待下一语义，应压缩。
- Hook 前 3 秒尤其严格，不允许明显 dead visual。

### 3. visual redundancy 不等于同源素材重复

08:92–09:97 使用 `DJI_20260801171222_0119_D.MP4` 06.200–07.250。

该段为接口、厚度、侧面电量灯特写，与开头正/背面手持展示明显不同。09:97–11:57 随后切入俯拍手机磁吸，构图、动作、信息三方面均发生真实变化。

新增/验证字段：

- `visual_redundancy`
- `same_action`
- `same_information`
- `same_composition`
- `new_visual_information`

规则：

即使源素材不同，只要动作、信息、构图高度重叠，也可能形成观众感知上的重复；必须以“是否提供新视觉信息”为判断依据。

### 4. 结构 B-roll 的保留边界

11:57–17:57 使用 `DJI_20260801171153_0118_D.MP4` 01.500–07.500。

约 13:0、16:0 可清楚看到 USB-C 接口和厚度，中间自然回到正面展示，没有机械端着接口不动。

该段未改是可接受的：

- 连续性自然
- 有结构信息增量
- 没有冒充 hotel wall plug Proof
- 现有记录中无更自然候选

唯一可选优化是 14:5–17:5 信息密度略有下降，但不足以单独再出一版，属于素材上限。

### 5. 已锁定优势均保持

- 03:50–04:97：手机 Charging / 绿色电池状态清楚，可读时间未缩水。
- 04:97–06:57：约 06:1 手表绿色充电动画清晰。
- 06:57–07:40：耳机仅放置，无自身充电反馈，继续标记 `partial_match / proof_missing`。
- 约 10:7：磁吸 snap 保持。
- 24:0–24:6：手指明确指向左下，CTA 与 `link below` 匹配。

未发现新的状态跳变、负向动作、Proof 损坏、节奏断裂或伪造 UI。

## 阶段性结论

当前素材下，纯剪辑阶段已经达到合理上限。

后续不应为了“继续优化”而继续重排素材。下一阶段应进入：

- 字幕
- 音效
- BGM
- CTA 包装

跨模型导演对照可作为模型能力实验，但不是这条成片继续交付的必要步骤。
