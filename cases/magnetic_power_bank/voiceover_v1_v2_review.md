# 充电宝口播驱动 V1 / V2 人工对比复盘

## 总结

V2 是实质提升，但不是全面胜出。V2 明显改善了手机 Charging、耳机对象匹配和 magnetic/snap 的语义峰值同步；同时牺牲了手表 Proof 的可读时间，并在后半段出现同源素材重叠、接口动作重复和“逐词打卡”式机械切镜。

最佳下一步不是 V1 或 V2 二选一，而是融合：

- 前半采用 V2 的表达意图与重音同步
- 手表恢复 V1 的结果停留
- 磁吸完整保留 V2 的结构预读 + snap 接触
- 12 秒后恢复 V1 的连续 B-roll 逻辑，避免 V2 重复接口
- `charging all your devices` 保留 V2 的多设备同框
- CTA 前恢复 V1 的“多设备总结 → hero”层次

## 人工逐帧纠正

- V2 手表绿灯首次明显可见约在 5.77 秒，而不是旧 analysis 的约 5.70 秒。
- V2 约 6.07 秒切走，绿灯完整可读时间只有约 0.30 秒。
- V2 13.20–16.40 秒包含同一源素材重叠使用，接口/侧面动作发生可感知重复。

## V1 优势

1. 手表绿灯 Proof 停留约 1 秒，视觉说服力明显强于 V2。
2. TSA/酒店前半段用连续产品运动，比 V2 的多个相似特写更自然。
3. 后半没有明显同源接口动作重放。
4. “多设备同框 → 单产品 hero”CTA 层次更清楚。
5. 功能模块之间稍有呼吸，状态重置感较弱。

## V2 优势

1. 产品更早在 `all I need` 附近揭示。
2. 手机 Charging 约 4.10 秒出现，正落在 `charges` 附近。
3. 耳机终于有独立真实放置动作，未伪造成功 Proof。
4. `no more carrying` 与线材清理动作更及时。
5. `magnetic` 先展示磁环，`snap` 附近发生真实接触，属于实质性动作重音设计。
6. `charging all your devices` 时切多设备同框，比 V1 的电量灯更贴语义。
7. A-roll / B-roll 分工更清楚。

## 两版共同问题

- 0–3 秒 Hook 都缺成熟广告级视觉冲击。
- 无 BGM、环境声、磁吸/转场音效，snap 视觉峰值缺声音强化。
- “正面给手机 / 背面给手表或耳机”的空间结构没有真正讲清。
- 手机、手表、耳机仍是三个独立功能模块，不是完整连续使用过程。
- TSA、酒店墙插、墙插后多设备充电、真实旅行场景、促销均缺直接素材。
- 后半大量灰色桌面手持产品，视觉疲劳。
- 无真实 sale 页面/价格/CTA 元素，转化闭环不足。

## 不应保留的 V2 行为

- 为了对词把手表 Proof 压到只有 0.30 秒。
- 13.20–16.40 秒重复使用同源接口/侧面动作。
- `traveling easier` 再放一段相似手持产品，造成信息重复。
- CTA 前连续两个近似手持镜头，削弱 hero 升级感。
- 每个短语都强制切一镜。

## 下一版推荐结构

- 0–5 秒：以 V2 为底，缩短 1.10–3.50 的静态产品停留。
- 5–7 秒：保留 V2 的“手表 → 耳机”结构，但恢复 V1 手表绿灯停留。
- 7–12 秒：以 V2 为底，完整保留 magnetic/snap 段。
- 12–17.5 秒：以 V1 连续 B-roll 为底，禁止重复接口动作。
- 17.5–19.3 秒：保留 V2 多设备同框。
- 19.3 秒以后：恢复 V1 “多设备总结 → hero”层次。

结论：V2 提升不是“只对词更准”。手机、耳机和 snap 都有真实进步；但手表 Proof、后半连续性和 CTA 收束发生退步。下一版必须融合，而不是继续单向加速“对词”。
