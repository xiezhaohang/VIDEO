误差归因

  1. 最大：in/out 与 source 内部 take/子段选择。 GT004、GT011 完全无 envelope overlap；GT007 也整体晚移。
  2. 第二：speed / hold / jump mapping。 六个普通连续镜头真人都约为 1.20× source progression，AI 一律用了 1.0×；GT009/GT010 还漏掉关键 hold 结构。
  3. Transition：没有造假转场，但没有找对 TR001/2 的 incoming motion 区间与长度。
  4. Action integrity：8/8 同 source 且内部不跨 take 拼动作；未发现“为了对词而破坏动作”。这条原则学到了，但它不足以产出真人 cut。
A. 目前不能说 AI 已经会剪。
B. 最大误差是内部 cut region / take choice，其次是 speed、hold、jump 与结果呼吸。
C. 先不要继续 Source Matcher；正确 source 已给定仍明显不够像，应先攻 source 内 action-state selection 与 mapping。
