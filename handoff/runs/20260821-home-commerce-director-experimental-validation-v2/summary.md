# Home Commerce Director Experimental Validation v2 — Framework Summary

- Status: `framework_ready_waiting_for_sample`
- Scope: prospective planning comparison only
- Control: existing Director
- Treatment: Knowledge Base v1 + Experimental Rule Layer v1
- Required input: one eligible unseen product, factual product brief and original source material
- Required outputs: purchase motivation, P/I/E/V scores, primary/secondary strategy, Hook hypothesis, required Proof, information-state plan, Hero, CTA and fallback
- Primary evaluation: strategy judgment accuracy, first purchase-meaning prediction, shot-task reasonableness and editor adoption willingness
- Guardrails: identical frozen inputs, isolated arms, pre-review output freeze, blind plan review, evidence-bound claims and explicit invalidation rules
- Not performed: sample selection, product analysis, editing, rendering, software change, `main` change or production-rule promotion

The next action belongs to the user only insofar as a new product and its original source material are needed. After receipt, the eligibility gate runs before either Director sees the sample.
