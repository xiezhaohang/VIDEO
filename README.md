# VIDEO — 商品实拍 AI 剪辑规则库

这个仓库用于长期维护“商品实拍素材 → AI 理解 → 候选镜头 → 动作质检 → 总编 → FFmpeg 成片”的通用方法。

目标不是只服务某一个产品，而是把每次项目中验证有效的经验沉淀为跨产品可复用规则。

## 使用方式

1. 新产品先填写 `templates/product_brief.yaml`。
2. 导演模型按 `docs/通用商品实拍AI剪辑规则库.md` 做全局理解。
3. 审片模型独立检查重复、信息未完成、错误 proof、过长展示等。
4. 关键动作进入高帧率质检。
5. 总编层只看清洗后的候选镜头和标签，负责顺序、节奏、删减和收尾。
6. 每次发现新规律，优先更新主规则和 `CHANGELOG.md`；某个产品的特有问题放入 `cases/`。

## 核心原则

- 先识别卖什么，再识别卖点。
- 不只判断“拍了什么”，还要判断“为什么拍”。
- 所有操作型镜头都必须剪到“起作用的那一刻”。
- 动作完成不等于信息完成；必须看到效果出现并稳定可读。
- 每个镜头都要维护 `state_before → action → state_after`，禁止状态倒退。
- 产品展示优先连续 360° 认知，碎片式多面展示只用于补缺。
- microcut 适合补充，不适合承担核心产品识别。
- 尽量挖掘每条素材的价值，但不强制所有素材进主线。
- 完全同义重复要删；同卖点但不同证据可以保留。
- AI 负责理解和决策，程序负责时间码校验、编码和执行。

## 当前结构

- `docs/通用商品实拍AI剪辑规则库.md`：主规则，持续实时更新
- `rules/universal_rules.yaml`：机器可读硬规则
- `templates/product_brief.yaml`：新产品任务模板
- `CHANGELOG.md`：版本演进记录
- `cases/magnetic_power_bank/lessons.md`：磁吸充电宝案例经验
